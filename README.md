# crypto-board

歪脖山@Web3 加密看板（GMGN / 早报 / 突发短讯）。

观察非买卖建议。数据由例行任务自动更新。

**看板地址（Pages 开启后）：** https://0xWinner98.github.io/crypto-board/

## 一次性开启 Pages（哥哥点一次）

打开：https://github.com/0xWinner98/crypto-board/settings/pages

任选一种：
1. **推荐（简单）**：Source 选 `Deploy from a branch` → Branch `main` → Folder `/ (root)` → Save
2. 或 Source 选 `GitHub Actions`，再到 Actions 里 Re-run `Deploy GitHub Pages`

开启后约 1 分钟可访问看板链接。
